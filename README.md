BACKUP / RESTORE

    dconf dump /org/gnome/shell/extensions/ > extensions.conf
    dconf load /org/gnome/shell/extensions/ < extensions.conf

==================================================

INSTALL SCRIPT (pywal + ghostty)

    chmod +x install.sh
    ./install.sh
